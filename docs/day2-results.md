# День 2. Формат ответа — результат

Дата: 2026-09-05. Реальные запросы к DeepSeek API, модель `deepseek-v4-flash`.

Одинаковый запрос в двух независимых историях:

> Предложи ПП-рецепт ужина с куриной грудкой и гречкой на одну порцию.

| Параметр | Без ограничений формата | С ограничениями |
| --- | --- | --- |
| System prompt | отсутствует | [формат ПП-рецепта](../src/recipe_prompt.txt) |
| Инструкция по длине | отсутствует | до 200 слов |
| max_tokens | 4096 | 1200 |
| stop | не отправляется | `["Готово"]` |
| temperature | 1.0 | 1.0 |
| thinking | disabled | disabled |
| Слов (по пробельным разделителям) | 457 | 175 |
| Символов | 2967 | 902 |
| finish_reason | stop | stop |

[Полные ответы API](day2-comparison.txt).

Без ограничений модель добавила вступление, советы и варианты ингредиентов.
КБЖУ приведены приблизительно на всё блюдо, без разбивки по продуктам.

С ограничениями ответ стал примерно на 62% короче по числу слов. Получены
название, число порций, 6 ингредиентов с КБЖУ, 3 шага, итог на блюдо и порцию.
КБЖУ в итоговой строке арифметически совпали с суммой значений ингредиентов:
412 ккал, Б 39,4 г, Ж 10,5 г, У 40,0 г. Это проверка сложения, а не проверка
пищевой ценности по внешней базе.

Формат соблюдён не полностью: вода из первого шага отсутствует в списке,
масса соли указана «по вкусу». Маркер «Готово» в полученном тексте отсутствует.
`finish_reason=stop` не отличает естественное завершение от пользовательского
маркера; сам по себе этот статус не доказывает срабатывание stop sequence.

Отдельная проверка запроса вне темы:

> Объясни ownership в Rust.

Ответ ровно:

> Я могу отвечать только на ПП-рецепты.

[Вывод проверки отказа](day2-refusal.txt).

Вывод: явный формат, инструкция по длине и параметры API сделали ответ короче
и предсказуемее в этом прогоне. System prompt не гарантирует соблюдение каждого
пункта или точность КБЖУ. Жёсткий лимит токенов может оборвать рецепт; CLI
предупреждает об этом при `finish_reason=length`.

Повторить эксперимент:

```bash
cargo run -- --compare 'Предложи ПП-рецепт ужина с куриной грудкой и гречкой на одну порцию.'
```

Ответы могут отличаться при повторном запуске. Конфиг должен использовать
встроенный prompt и параметры из `deepseek.example.toml`.
