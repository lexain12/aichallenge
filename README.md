# DeepSeek CLI

Небольшой интерактивный клиент DeepSeek на Rust. По умолчанию составляет ПП-рецепты
с КБЖУ каждого ингредиента, итогом на блюдо и порцию. Ответ печатается по мере
генерации, а история текущего диалога хранится только в памяти процесса.
Реплики пользователя и DeepSeek выделяются разными фоновыми полосами на всю
ширину терминала.

## Сборка

```bash
cargo build --release
```

Готовый исполняемый файл: `target/release/deepseek-cli`. При желании его можно
установить в Cargo bin-каталог:

```bash
cargo install --path .
```

## Настройка

Создайте локальный конфиг из примера:

```bash
cp deepseek.example.toml deepseek.toml
```

Вставьте API-ключ в `api_key`. Файл `deepseek.toml` исключён из Git, однако его
всё равно следует считать секретным и не пересылать другим людям.

Ключ также можно передать переменной окружения; она имеет приоритет над файлом:

```bash
DEEPSEEK_API_KEY='your-key' deepseek-cli
```

Доступные параметры:

```toml
api_key = "replace-with-your-key"
base_url = "https://api.deepseek.com"
model = "deepseek-v4-flash"
# system_prompt по умолчанию встроен из src/recipe_prompt.txt
temperature = 1.0
max_tokens = 1200
stop = ["Готово"]
timeout_seconds = 120
```

Кроме ключа, все поля необязательны и принимают показанные значения по
умолчанию. Другой файл можно выбрать явно:

```bash
deepseek-cli --config /path/to/config.toml
```

## Использование

```text
$ deepseek-cli
you> Предложи ПП-рецепт ужина с курицей
assistant> ...ответ появляется постепенно...
you> /exit
```

Команды:

- `/clear` — очистить историю текущего сеанса;
- `/exit` или `/quit` — выйти;
- Ctrl+D — выйти.

Если запрос оборвался или API вернул ошибку, незавершённая пара сообщений не
добавляется в историю.

Цвета автоматически отключаются при перенаправлении вывода. В интерактивном
терминале их можно отключить вручную стандартной переменной `NO_COLOR`:

```bash
NO_COLOR=1 deepseek-cli
```


## День 2: контроль формата ответа

Встроенный system prompt находится в `src/recipe_prompt.txt`. Он задаёт:

- один рецепт: название, порции, ингредиенты с массой и КБЖУ для этой массы;
- от 2 до 5 шагов приготовления, итог КБЖУ на блюдо и на порцию;
- до 6 ингредиентов и до 200 слов;
- завершающий маркер `Готово`;
- на запрос вне темы — ровно `Я могу отвечать только на ПП-рецепты.`

Это инструкции модели: формат, отказ, число слов и арифметика не гарантируются
кодом. КБЖУ приблизительные, без внешней базы пищевой ценности.

API получает `max_tokens = 1200` и `stop = ["Готово"]`. Ограничивается длина
**ответа**, не пользовательского промпта. Маркер остановки не отображается в
ответе. При `finish_reason=length` CLI предупреждает об обрезанном ответе и не
сохраняет его в истории. `finish_reason=stop` может означать как естественное
завершение, так и срабатывание маркера; по этому полю их различить нельзя.

Для одинаковых условий в обоих режимах явно отключён thinking
(`thinking.type = "disabled"`), чтобы небольшой бюджет не расходовался на
скрытое рассуждение. Параметры описаны в
[документации DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion/).

Чтобы вводить запросы после запуска:

```bash
cargo run -- --compare
```

На каждый введённый запрос CLI покажет два ответа, затем снова предложит ввод.
Каждая пара использует независимые пустые истории. Пустая строка пропускается,
`/exit`, `/quit` или Ctrl+D завершают программу.

Запустить один и тот же запрос без ограничений формата и с ними и выйти:

```bash
cargo run -- --compare 'Предложи ПП-рецепт ужина с куриной грудкой и гречкой на одну порцию.'
```

Команда делает два реальных API-запроса, печатает оба ответа, количество слов,
символов и причину завершения. Истории независимы; модель, температура и текст
запроса одинаковы. Базовый режим не отправляет system prompt и `stop`, но имеет
технический предел 4096 токенов. Контролируемый режим берёт настройки из конфига:
для упражнения используйте встроенный prompt и значения из примера. Один прогон
показывает пример поведения, а не гарантирует соблюдение формата на всех запросах.

Для обычного диалога без ограничений формата:

```bash
cargo run -- --unrestricted
```

`system_prompt`, `max_tokens` и `stop` можно переопределить в TOML. `stop = []`
отключает пользовательские маркеры. Если в старом конфиге остался
`system_prompt = "You are a helpful assistant."`, удалите эту строку, чтобы
использовать встроенный формат рецепта.
