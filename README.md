# DeepSeek CLI

Небольшой интерактивный клиент DeepSeek на Rust. Ответ печатается по мере
генерации, а история текущего диалога хранится только в памяти процесса.
Реплики пользователя и DeepSeek выделяются разными фоновыми полосами на всю
ширину терминала.

## День 6: отдельный агент

`Agent` в `src/agent.rs` — структура с методами (аналог класса в Rust).
Она владеет API-клиентом и собственной историей диалога. Терминал отвечает
за ввод и отображение; агент составляет запрос, вызывает API и сохраняет
успешную пару «пользователь — ассистент». В шестом дне используется
один агент и один интерактивный чат в терминале.

```rust
use deepseek_cli::{agent::Agent, config::Config};
use std::path::Path;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let config = Config::load(
        Path::new("deepseek.toml"),
        std::env::var("DEEPSEEK_API_KEY").ok(),
    )?;
    let mut agent = Agent::new(&config)?.with_prompt("Объясни ownership в Rust");

    println!("{}", agent.run().await?); // Использует заранее заданный промпт.
    println!("{}", agent.run_with_prompt("Теперь покажи пример").await?);
    // Второй запрос включает первый вопрос и ответ.
    assert_eq!(agent.history().turn_count(), 2);
    agent.clear_history();
    Ok(())
}
```

- `with_prompt(...)` задаёт пользовательский промпт для `run()`.
  Без него `run()` возвращает ошибку до обращения к API.
- `run_with_prompt(...)` отправляет переданный промпт и возвращает полный ответ;
  промпт по умолчанию при этом не меняется.
- `run_streaming(prompt, callback)` передаёт фрагменты текста и статистику
  токенов в callback и также возвращает полный ответ.
- `history()` даёт доступ к истории для чтения; `clear_history()` очищает
  реплики, сохраняя system prompt и промпт по умолчанию.

System prompt берётся из конфигурации и задаёт общие инструкции агенту.
Каждый запуск добавляет новый ход диалога. Пустой пользовательский промпт
отклоняется локально; ошибки API, пустые, обрезанные и оборванные ответы
не меняют историю. История хранится **в памяти до завершения процесса**,
без восстановления после перезапуска.

Запуск интерактивного чата: `cargo run`. Режимы сравнения доступны
в ветках предыдущих дней; команды запуска перечислены в [списке дней](docs/DAYS.md).

## Сборка

```bash
cargo build --release
```

Готовый исполняемый файл: `target/release/deepseek-cli`. При желании его можно
установить в Cargo bin-каталог:

```bash
cargo install --path .
```

## Настройка

Создайте локальный конфиг из примера:

```bash
cp deepseek.example.toml deepseek.toml
```

Вставьте API-ключ в `api_key`. Файл `deepseek.toml` исключён из Git, однако его
всё равно следует считать секретным и не пересылать другим людям.

Ключ также можно передать переменной окружения; она имеет приоритет над файлом:

```bash
DEEPSEEK_API_KEY='your-key' deepseek-cli
```

Доступные параметры:

```toml
api_key = "replace-with-your-key"
base_url = "https://api.deepseek.com"
model = "deepseek-v4-flash"
system_prompt = "You are a helpful assistant."
temperature = 1.0
max_tokens = 4096
timeout_seconds = 120
```

Кроме ключа, все поля необязательны и принимают показанные значения по
умолчанию. Другой файл можно выбрать явно:

```bash
deepseek-cli --config /path/to/config.toml
```

## Использование

```text
$ deepseek-cli
you> Объясни ownership в Rust одним абзацем
assistant> ...ответ появляется постепенно...
you> /exit
```

Команды:

- `/clear` — очистить историю текущего сеанса;
- `/exit` или `/quit` — выйти;
- Ctrl+D — выйти.

Если запрос оборвался или API вернул ошибку, незавершённая пара сообщений не
добавляется в историю.

Цвета автоматически отключаются при перенаправлении вывода. В интерактивном
терминале их можно отключить вручную стандартной переменной `NO_COLOR`:

```bash
NO_COLOR=1 deepseek-cli
```
